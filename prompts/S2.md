# Prompts for S2: Conditionally Insert into a Nested List (`id_q4.rkt`)

Each prompt below corresponds to a single unit of work (one function, one refactor, one test file, or one review), following the `scheme-dev` skill constraints (`#lang racket/base`, restricted built-ins only, tail recursion where natural, and no top-level execution).

---

## Unit 1: `my-length`
**Prompt:**
> Write a Scheme function `(my-length lst)` in `#lang racket/base` that returns the number of top-level elements in a proper list `lst`. Use tail recursion with an accumulator so it handles lists of 10,000 elements safely. Use only these built-ins: `define`, named `let`, `if`, `null?`, `cdr`, `+`. Include a brief comment giving the recursive reading.

---

## Unit 2: `my-reverse`
**Prompt:**
> Write a tail-recursive Scheme helper function `(my-reverse lst)` in `#lang racket/base` that reverses a proper list `lst`. Use only `define`, named `let`, `if`, `null?`, `cons`, `car`, `cdr`, and `'()`. Include a brief comment explaining its accumulator invariant.

---

## Unit 3: `my-map`
**Prompt:**
> Using the `my-reverse` helper we defined, write a tail-recursive Scheme function `(my-map proc lst)` in `#lang racket/base` that applies unary function `proc` to each element of `lst` from left to right and returns the resulting list in original order. Use only `define`, named `let`, `if`, `null?`, `cons`, `car`, `cdr`, `'()`, and `my-reverse`. Ensure it handles lists of 10,000 elements without growing the call stack.

---

## Unit 4: `my-list?`
**Prompt:**
> Since `list?` is not in the allowed built-ins for S2 and inputs are guaranteed to contain no dotted pairs (only atoms and proper lists), write a small helper function `(my-list? val)` in `#lang racket/base` using only `define`, `or`, `null?`, and `pair?`.

---

## Unit 5: Initial `insert-if-short` (S2.b)
**Prompt:**
> Write `(insert-if-short x lst n)` in `#lang racket/base` using `my-length`, `my-map`, and `my-list?`. It should insert atom `x` at the front of every list at every level of nesting (including the top-level list and empty lists `()`) whose original top-level length is strictly less than `n`. Use only the allowed built-ins from the S2 specification.

---

## Unit 6: `make-inserter` (S2.c)
**Prompt:**
> Write a higher-order Scheme function `(make-inserter x len-ok?)` in `#lang racket/base` that returns a function of one argument (`lst`). The returned function must traverse `lst` at every level of nesting (including the top-level list and empty lists `()`) and insert `x` at the front of every list whose original top-level length satisfies `(len-ok? len)`. Use `letrec`, `lambda`, `let`, `if`, `cons`, `my-map`, `my-length`, and `my-list?`.

---

## Unit 7: Refactor `insert-if-short` to use `make-inserter` (S2.c)
**Prompt:**
> Replace the previous definition of `(insert-if-short x lst n)` so that it is defined directly in terms of `(make-inserter x len-ok?)`, keeping only this single definition of `insert-if-short` in the file.

---

## Unit 8: `print-insert-result` (S2.a)
**Prompt:**
> Write `(print-insert-result)` in `#lang racket/base` taking no arguments. Using `let*` and `read`, read `x`, `lst`, and `n` in that exact order from standard input, call `(insert-if-short x lst n)`, and print the result with `display` followed by `newline`. Do not print any prompt or extra text, and do not add any top-level function calls.

---

## Unit 9: Test File for S2
**Prompt:**
> Write a separate Racket test script `tests/test_q4.rkt` that tests `id_q4.rkt` against all four examples from the S2 specification, plus edge cases: deeply nested empty lists, `n = 0`, custom predicates passed to `make-inserter`, nesting depth 100, and a flat list of 10,000 elements. Also test `print-insert-result` via simulated standard input.

---

## Unit 10: Final Review & Constraint Audit
**Prompt:**
> Review `id_q4.rkt` against every S2 requirement:
> 1. Starts with `#lang racket/base` and contains only definitions (no top-level calls or printing).
> 2. Uses strictly the allowed built-ins (no `length`, `map`, `reverse`, `append`, `list?`, `set!`, strings, vectors, or loops).
